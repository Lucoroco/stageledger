# Security policy

## Supported versions

StageLedger is an early prototype. The latest version on `main` receives security fixes on a best-effort basis.

## Reporting vulnerabilities

Please do **not** publish exploitable security issues or sensitive information in public GitHub issues. Use the repository's private vulnerability reporting option if enabled, or contact the maintainer through a private channel listed on the GitHub profile. If no private channel is available, open an issue requesting a secure reporting contact without sharing the vulnerability details.

## Data handling

StageLedger processes local JSON files and does not send event or inventory information to a server. Do not submit real customer data, credentials, names, phone numbers or addresses in public bug reports.
