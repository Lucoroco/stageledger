# Contributing to StageLedger

Thanks for considering a contribution. The project is an early prototype and practical feedback from community groups is especially valuable.

## Development

1. Fork the public repository and make a branch with a descriptive name.
2. Use Python 3.10 or later; no third-party runtime dependencies are needed.
3. Run `python -m unittest discover -s tests -v`.
4. Include a regression test when correcting a bug.
5. Open a pull request that explains what changed, why, and how it was tested.

## Good first contributions

- Add a test covering a tricky timezone or overlapping-booking case.
- Improve README instructions for Windows PowerShell.
- Translate sample documentation without changing JSON field names.
- Suggest an accessible format for printable packing lists.

## Issues and pull requests

Search existing issues first. Provide the minimum reproducible sample needed to explain the issue. Don't include customers' contact details or other private information.

Please keep discussions respectful, and explain technical disagreements with examples.
