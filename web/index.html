SUPPORT / TRUST

Built to stay simple.

A transparent, open-source planning tool for community event organisers.

① Start with your equipment

Add items manually or import an inventory CSV. Quantity represents the number of interchangeable units in stock.

② Create your event schedule

Add event times, setup and teardown buffers, and the equipment quantity required for each event.

③ Inspect availability

StageLedger calculates the maximum simultaneous reservations and flags items that cannot cover an event.

④ Export your work

Save your inventory, event schedule and printable packing lists before closing the tab. Changes are not automatically stored.

Privacy by design

This interface runs entirely inside your browser. No sign-in, external scripts, analytics or web API requests are required. Your files are parsed locally. Because edits are not automatically saved, export your JSON files to retain them.

Limits: pooled equipment counts only; no serial-number tracking, physical condition checks, travel estimates, crew scheduling or supplier booking. Publicly shared examples are fictional and do not prove external adoption.
